# Interactive To-Do List with LocalStorage

## CodeAlpha Project 02

A responsive task manager developed using HTML5,
CSS3 and JavaScript.

## Features

1. Add new tasks.
2. Mark tasks as completed.
3. Delete individual tasks.
4. Filter All, Active and Completed tasks.
5. Clear completed tasks.
6. Display remaining task count.
7. Save tasks using LocalStorage.
8. Responsive mobile and desktop design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- LocalStorage

## Project Files

todo_list_project/

- index.html
- style.css
- script.js
- README.md

## How to Run

1. Download the project files.
2. Open the folder in Visual Studio Code.
3. Open index.html in Google Chrome.
4. Enter a task in the input box.
5. Click Add Task.
6. Mark tasks as completed or delete them.
7. Refresh the page to test LocalStorage.

## LocalStorage

LocalStorage saves tasks in the browser.

Tasks remain saved after refreshing the page
in the same browser on the same device.
